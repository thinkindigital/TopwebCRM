# Referencia externa: OpenWA

O TopwebCRM integra o OpenWA, mas nao incorpora sua documentacao completa como documentacao de produto.

- Repositorio: https://github.com/rmyndharis/OpenWA
- Versao auditada pelo TopwebCRM: `0.23.0`
- Contrato usado: `docs/topweb-chat/OPENWA.md`
- OpenAPI canonico: `openapi.json` no repositorio OpenWA da versao auditada

Ao atualizar o OpenWA, comparar o OpenAPI e os testes de contrato antes de alterar esta versao. Roadmap, plugins, infraestrutura e recursos do OpenWA nao sao compromissos do TopwebCRM.
